# Beacon

Office door LED sign powered by an ESP32 and a P4 HUB75 panel.

Flashes animations to mark your office and displays custom messages on demand — controlled via a simple HTTP API or the companion web client.

## Features

- 64×32 P4 LED panel (256×128mm) — visible from several meters
- Idle animations — cycles when no message is active
- HTTP API — update the display from any device on the network
- Mobile-friendly web client — send messages from your phone

## Hardware at a Glance

| Component | Detail |
|---|---|
| Panel | P4 HUB75, 64×32 dots, 256×128mm, 1/16 scan, SMD |
| Brain | ESP32 |
| Power | 5V 4A PSU |
